==================================================
一、怎么重新上传
==================================================

推荐直接覆盖 GitHub 仓库，因为你的 Vercel 已经和 GitHub main 分支关联过。

1. 下载并解压 Premier-Ticket-Tracker-COMPLETE.zip
2. 打开 GitHub 仓库：
   GuidaoPao0529 / premier-ticket-tracker
3. 进入 main 分支根目录
4. Add file → Upload files
5. 把【解压后的文件和文件夹】全部拖进去
   注意：
   - 不要上传 ZIP 本身
   - .github 文件夹一定要保留
   - api 文件夹一定要保留
   - scripts 文件夹一定要保留
6. Commit changes
7. 等 GitHub 提交完成
8. Vercel 会因 GitHub push 自动重新部署
9. 通常几十秒到几分钟后刷新：
   https://premier-ticket-tracker.vercel.app/

==================================================
三、自动更新怎么工作
==================================================

GitHub Actions 每小时运行一次。
它只检查：
- Arsenal 官方票务
- Chelsea 官方票务
- Manchester United 官方票务
- Manchester City 官方票务

规则：
- 只使用俱乐部官网
- 读取失败不修改原数据
- 不推测 Ballot/Application 精确日期
- 只在官方页面明确匹配到比赛和状态关键词时更新
- 有变化 → 自动 commit 到 main
- GitHub push → Vercel 自动部署
- iPhone 仍订阅同一个 .ics 地址，因此之后会拿到新内容

注意：
iPhone 自己多久刷新一次订阅日历由 Apple 控制，不保证分钟级实时。
ChatGPT 的四队票务 Watch 仍适合作为“即时提醒”；日历适合保存和持续同步。

五、重要说明
==================================================

部分俱乐部（尤其 Arsenal/登录票务系统）会使用 JS、Cloudflare、登录验证或 403。
自动脚本采取“宁可不改，也不猜错”的策略：
读不到时保留上一次已确认数据，不会乱填时间。

真正出现 Ballot/Application 新时间时：
- ChatGPT Watch 会尽快提醒你
- 自动脚本若能从公开官网读到，会提交更新
- Vercel 随之部署
- iPhone 日历随后同步


==================================================
六、当前会员资格
==================================================

Arsenal：Red Member
Chelsea：CFC Blue

Chelsea 页面和日历按 CFC Blue 资格判断。
CFC Blue 官方权益包括 Ticket Application Window 的专属/预留票池机会，
并可使用 Ticket Exchange。若某场有 loyalty points 门槛，仍以该场官方公告为准。

【北京时间说明】
新版 iPhone 日历统一使用 Asia/Shanghai。英国夏令时期间通常 +7 小时，冬令时期间通常 +8 小时，由程序按日期自动换算。

【每周比赛日历】
新版订阅日历会把网站中四队未开赛主场比赛加入 iPhone 日历。
事件标题直接显示“北京时间 + 对阵”，并默认提前 1 天、2 小时提醒。
以后 tickets.json 增加正式比赛后，同一订阅日历会自动出现该场比赛。

【新版 iPhone 日历标题】
事件前缀区分类型：【比赛】【Ballot】【申请】【会员购票】【Exchange】。
队名改为中文短名，比赛标题直接带北京时间，方便在 iPhone 月/周视图里快速扫一眼。

【重要：这版使用新的 iPhone 订阅地址】
为了绕过 iPhone 对旧订阅源的缓存，请部署后删除手机中旧的 Premier Ticket Tracker 订阅，
然后重新订阅：

https://premier-ticket-tracker.vercel.app/iphone-cn.ics

或：
webcal://premier-ticket-tracker.vercel.app/iphone-cn.ics

新日历名称：四队票务｜北京时间

标题示例：
【比赛】切尔西-赫尔城 09/12 22:00
【Ballot】阿森纳-里尔 开
【申请】切尔西-伯恩茅斯 截止

旧地址 /premier-ticket-tracker.ics 仍兼容，但本次建议重新订阅新地址，
这样可以强制 iPhone 拉取最新格式，避免继续显示旧缓存。
